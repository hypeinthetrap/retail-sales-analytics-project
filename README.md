# Retail Sales Analytics Project (SQL + Python)

## Overview
This project demonstrates an end-to-end retail analytics workflow using **Python, SQL, and SQLite**.  
The goal is to simulate how raw transactional data can be transformed into a structured database and queried to answer meaningful business questions.

The project focuses on:
- Data exploration and validation
- Database design and construction
- SQL-based analytics
- Python–SQL integration using SQLite

## Tech Stack
- **Python** (pandas, sqlite3)
- **SQL** (SQLite)
- **VS Code**
- **Git & GitHub**
